# Журнал сабмитов

Лимит платформы: **5 сабмитов в сутки на команду**, сброс в 00:00 МСК.
Публичный лидерборд считается по public-выборке, итоговая автооценка — по private.
Эталон и baseline команде не отдают. Каждый сабмит проверяет одну гипотезу.

ZIP собирает `python package_zip.py`. В архив не входят база знаний, `questions.csv` и `.env`.

| # | Гипотеза | Дата (МСК) | Score | Что изменилось в коде | Вывод |
|---|---|---|---|---|---|
| 1 | Полный текст разделов и форма ответа как в `demo_output.csv`. Цель — балл выше нуля. | | | | ещё не отправлен |
| 2 | Чанки по заголовкам и роутер по `00-product-map.md`. | | | | ещё не отправлен |
| 3 | Парсер диалога на вопросах 14–18. | | | | ещё не отправлен |
| 4 | Границы из файла 02 и цифры из файла 01. Отказ, если нужного абзаца нет. | | | | ещё не отправлен |
| 5 | Параллельность по `MAX_WORKERS` внутри 20 минут. Реранкер — только если прогон и без него быстрый. | | | | ещё не отправлен |

Если суточный лимит исчерпан, следующая строка — на завтра. Не отправляйте повторно тот же ZIP.
